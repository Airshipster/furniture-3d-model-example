# Контекст проекта: 3D furniture

## Что это

Интерактивная презентационная 3D-модель корпусного шкафа. Это не рабочий чертёж и не карта раскроя: окончательное производство, крепёж, нагрузки и монтаж подтверждает мастер.

## Актуальная версия

- Публичная модель: https://airshipster.github.io/furniture-3d-model-example/
- Репозиторий: https://github.com/Airshipster/furniture-3d-model-example
- Русский — по умолчанию; азербайджанский: `?az`.
- Рабочая ветка: `main`.

## Источник истины для меток

Текущая утверждённая раскладка оранжевых размерных линий сохранена в `index.html` в объекте `fixedDimensionOffsets`. В ней 43 метки, в том числе индивидуально проверенные позиции правой секции.

Эти позиции нельзя пересчитывать, округлять, нормализовать или заменять единым шаблоном по долям проёма. Доли 0%, 25%, 33 1/3%, 50%, 66 2/3%, 75% и 100% применяются только как точки прилипания при проверке. Для каждого проёма утверждённая позиция может быть своей.

Если раскладка меняется при локальном просмотре, перед публикацией нужно скопировать весь новый сохранённый набор позиций в `fixedDimensionOffsets` и проверить совпадение количества и всех значений. Не переносить отдельные секции вручную и не брать старый снимок.

## Основные документы

- `METHODOLOGY.md` — универсальные правила создания и проверки модели.
- `MODEL_SPEC.md` — текущие габариты, материалы, секции, фасады и правила отображения.
- `README.md` — краткий вход в проект и ссылка на публикацию.

## Техническая заметка

Опубликованная версия загружает Three.js из CDN, поэтому в GitHub Pages не требуется папка `node_modules`. Локальный сервер для готовой модели не нужен и остановлен.
